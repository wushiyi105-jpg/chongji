# UI 说明：宠记

- **谁在什么时刻打开**：给多宠或多人照护的家庭。
- **首屏任务句**：下一件事，别错过。
- **主操作**：按「先选对宠物 → 记下这次观察 → 带走就诊近况」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：宠物护照；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：宠物护照。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给多宠或多人照护的家庭：把体重、疫苗、驱虫和观察记录归到每只宠，切宠后名字、照片和记录一起切换。
